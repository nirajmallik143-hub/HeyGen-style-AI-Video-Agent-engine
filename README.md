# 🎬 HeyGen-Style AI Video Agent Engine

An open-source, local-first alternative to HeyGen, D-ID, and Synthesia. Generate realistic talking-head presenter videos from a single portrait and a text prompt.

## 🚀 Features

- **Free Neural TTS**: Microsoft Edge Neural TTS voices (multi-language & accents) with no API keys.
- **Agentic Scriptwriting**: Automated script generation via local LLMs (Ollama) or external APIs.
- **Lip-Sync & Animation**: Modular support for SadTalker, Wav2Lip, and LivePortrait.
- **Web Studio**: Intuitive Gradio UI for fast generation and previewing.
